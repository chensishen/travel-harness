## 已修复的实际缺陷

1. 失败旧任务缺少结束时间时，阶段计时持续增长：停止任务改用最后事件时间。
2. 429统一误报网络/权限问题：区分额度耗尽与请求过频，返回可采取行动的提示，不回显外部响应中的密钥。
3. 复制任务只复制文字：同时恢复天数、人数、预算和日期；新建按钮能清空当前草稿。
4. 收起高级设置导致参数丢失：展开状态与是否应用参数分离；折叠后的非法人数同样拦截。
5. 网页预览与正式交付物不一致：使用交付物的默认说明，显示配图限定说明、备选时段及每个核实对象链接，按既有交付规则隐藏内部审阅提示。
6. 缺少结构化JSON下载入口：补齐已存在交付物的下载卡片。
7. 中断任务和采集任务状态标题不准确：分别显示等待解决、正在采集资料。

涉及文件：`frontend/src/App.tsx`、`frontend/src/types.ts`、`backend/harness/progress.py`、`backend/harness/graph.py`，以及相应回归测试。未修改正式上海样例的交付内容。
