# 文档排版改造验收

日期：2026-10-28。

## 修改

采用已提供的 Presentations、Documents 技能的视觉设计与渲染检查流程，参考官方 pptx、docx 技能调研结果。保留现有 Python 技术栈，不复制、安装或分发第三方技能实现。

- `backend/render/documents.py` 准备共享资料、合并完全相同的事实表行，并生成缩放后的内嵌图片；原始插画与研究数据保留。
- `backend/render/slides.py` 分别编排大图封面、阅读导览、路线、原生时间轴、交替图文主题页、双景点图文页和附录；取消每 110 字切页。
- PPT 只选取可容纳的完整原文句子，不硬截断句子、删除条件或调用模型改写事实。长材料、完整事实表、来源链接和待核验清单保留在备注中。
- `backend/render/word.py` 负责报告封面、阅读导引、章节图文、参观信息表、完整来源与核验附录。统一中文字体、标题层级、图注、页码及表格样式，去除默认标题蓝色横线。
- `backend/render/map_renderer.py` 将景点名称移到图例，点位显示编号；地图范围包含实际路线线段，减少标签挤压与路线裁切。
- `backend/render/preview.py` 在独立 LibreOffice 配置与中文字体环境中转换 PPT、Word；先删除旧 PDF，避免转换失败后误用旧文件。应用的 PPT 页面预览接口保持不变。
