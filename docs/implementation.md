## 与完整 PRD 的差距

1. 三个模型已完成真实连通性和基础语义区分测试；这些小样本结果不能替代整份内容的事实准确率验收。详细结果见 `docs/live-test-report.md`。
2. `poi_facts` 当前存于每任务结构化 JSON，尚未建立独立 Milvus 集合。知识块默认 `doc_type=intro`，尚未完成所有事实字段分类、语义标题分块与只补抓缺失字段的精细化更新。
3. 路线能报告数量、总时长与长路段例外，但尚未对所有失败约束自动调整分组；坐标双来源交叉验证、闭馆日、营业窗口、地铁站、住宿区域标记仍待实现。导出图是明确标注的示意图，尚未用 Leaflet 截图替代。
4. 当前配图为 AI 文化意象插画，不是实景照片。图片 Embedding 输入已探测成功；自动视觉审核与相关性精筛尚待接入，不能宣称图文相关率已达标。
5. 前端使用手写 CSS，尚未按 PRD 迁入 Tailwind / shadcn/ui。默认自动大纲；大纲人工确认面板未实现。
6. 已增加历史节点时间轴：从有来源的事实正文提取明确年份、按年代排列并标注节选，不代表完整历史年表。预算、交通、美食是否完整依赖实际研究证据。Word 已有参观信息表，预算与每日行程的专用表模板尚未完成。
7. 已有节点耗时、来源数、状态与错误；token 使用量统计、长材料分层摘要、标准化模型评测报告仍待实现。
8. 没有宣称达到事实准确率 ≥95%、图文相关率 ≥90%、单城市 ≤8 分钟等指标；这些需要真实模型、真实数据与抽检记录。
