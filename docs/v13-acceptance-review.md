## 未满足项

### 1. P0 预算遗漏已核实门票

对应15.4第5条：预算按人数计算门票、市内交通和餐饮合计。

上海PPT第20页已写出豫园旺季成人40元、宋庆龄故居成人原价20元，两人应分别计80元、40元。然而第21页合计为520–1120元，并把这两项列为“未核实门票”。Word预算表也有同样问题。

原因：`backend/harness/visit_context.py:330`的价格提取只识别紧接数字的“成人票20元”，不能识别“成人票旺季（……）每位40元”或“成人票原价20元”。两项金额数组为空，合计只计入犹太难民纪念馆40元。

按当前保存的已核实票价、2026-11月旺季和两人三天的相同预算口径，仅补回这两项后应为640–1240元。该区间仍不含其他未核实门票、到达和离城费用；不是完整旅行总价。

### 2. P0 上海博物馆未按参观日期与馆区组织内容

对应第2章第6条、第5章第5及8条、15.4与15.5：目标馆区、有效事实和实际参观内容须一致。

行程安排2026-11-08参观人民广场馆。最终PPT第16页、Word第20页仍介绍东馆的8个常设展厅，以汝窑展品照片配图，未告知人民广场馆当期的展览限制；预约字段同时为“待核实”。

上海博物馆自己的[人民广场馆参观须知](https://www.shanghaimuseum.net/mu/frontend/pg/service/visit-west)已明确：2026-07-09至2027-11-14为“世界树之巅：美洲古代文明大展”期间，人民广场馆不再展出其他展览，常设展应前往东馆；散客可通过官方小程序预约购票。

这段公告已经存在于任务缓存来源S55，不是复核时才出现的新公告。因此，“已抓到资料但未落实到正文和预约字段”是可复现的遗漏。历史馆藏图片本身不等于图片造假，但此处缺少当期展陈说明，会误导参观预期。

### 3. P0 备选表未提供至少三个明确替换时段

对应15.1第6条：至少3个替换候选，注明可替换哪一时段及原因。

上海PPT第30–31页及Word第33页使用“任一天同类时段”“第1天至第3天同类型时段”。没有明确替换哪一天、哪一站或哪个时间窗口；表中还混有重复实体、无坐标和闭馆项。这些项可保留作未纳入说明，但不能据此证明已有3个明确替换方案。

生成位置：`backend/tools/planning_v13.py`中剩余候选统一填写上述通用时段。审计脚本只检查`replace_day`非空，未验证时段是否具体。

### 4. P1 自动审计有假通过，不能代替完整验收

在上海state的内存副本中，将全部`map_png`清空、`map_coverage`置0，审计仍返回`passed=true`。原state和交付物未修改。

原因：`scripts/audit_v13.py:164`使用`require_maps=all(d.map_png for d in typed.days)`；地图缺失反而关闭地图检查。实际Assembler还会单独检查地图，因此本项证明的是独立审计脚本漏检，不能推断实际发布链必然允许无地图出件。

另有两项检查过弱：预算只检查是否存在“合计”及非空金额数组；备选只检查数量与时段字段非空。它们均未识别本次真实错误。

复现记录：`data/qa/v13/acceptance-review-evidence.json`。

### 5. P1 路线版式未遵循约定的同页布局

对应当前任务书第3章第4条、第8章：PPT路线页约60%地图、40%时间轴。

上海每日地图和时间轴仍分别占两页（第5/6、7/8、9/10页）。`backend/render/slides_v11.py:172–199`的v1.3分支明确新建独立时间轴页。虽能阅读、没有因此证明发生裁切，但未按任务书约定实现路线同页布局。
